SIDBOX 3D Library Manual

This is a practical guide for the current helper layer. It is meant to make the library easier to use without having to remember every function from memory. The focus is gameplay-facing helpers, mesh utilities, and deformation tools.

1. Core Ideas

Entity movement Moves an object in the world by changing Entity.pos and often Entity.prevPos. This is normal gameplay movement.
Mesh movement Moves or changes the actual vertex data inside the mesh. This changes the shape, not the world position of the entity.
Local vs Global Global means world axes. Local means entity axes. For example, local +Z means “forward relative to current facing.”
Important: entityTranslate() and meshTranslate() are not the same kind of operation. One moves the object in the world. The other shoves the raw mesh vertices around.

2. Core Types

Vec3

Basic 3D vector with x, y, and z. Used for positions, directions, deltas, scales, and angles in some helpers.

Tri

Triangle face. Holds indices a, b, c and visual fields like color, emission, transparency, and roughness.

Mesh

Raw geometry container. Holds vertices, triangles, edges, bounds radius, and material.

Entity

World instance of a mesh. Holds world position, previous position, basis vectors, flags, collision setup, and a pointer to the mesh.

3. Entity Helpers

int entityIdValid(int id)

Checks whether an entity slot is in range, active, and has a mesh.

int entityWorldSpawn(Mesh *mesh, Vec3 pos)

Creates a new entity in the world, sets default basis axes, default visibility, and clears collision values.

Returns the entity id on success, or -1 if no free slot exists.

void entityWorldDestroy(int *id)

Destroys an entity and resets the slot. Also sets the caller’s id to -1.

void entitySetPosition(int id, Vec3 pos)

Hard-sets the world position. Also updates prevPos to the same value.

Vec3 entityGetPosition(int id)

Returns the entity position. Invalid ids return {0,0,0}.

Vec3 entityGetForward(int id)
Vec3 entityGetRight(int id)
Vec3 entityGetUp(int id)

Returns entity basis vectors. Invalid ids return sensible defaults.

4. Movement Helpers

void entityMove(int id, Vec3 delta)

Moves the entity in world space by a delta.

void entityMoveForward(int id, float dist)
void entityMoveRight(int id, float dist)
void entityMoveUp(int id, float dist)

Moves the entity along its local basis vectors.

void entityTranslate(int id, Vec3 delta, uint8_t global)

Moves an entity either in world space or in local space.

  • global = 1 → delta is treated as world-axis movement
  • global = 0 → delta is treated as local-axis movement
entityTranslate(id, (Vec3){ 1.0f, 0.0f, 0.0f }, 1); // world +X
entityTranslate(id, (Vec3){ 0.0f, 0.0f, 1.0f }, 0); // local forward
void entityTurnLocal(int id, float yaw, float pitch, float roll)
void entityTurnGlobal(int id, float yaw, float pitch, float roll)
void entityRotation(int id, float yaw, float pitch, float roll, uint8_t global)

Rotation helpers for local or world-style turning.

5. Distance / Automation

void entityMoveTowardsPosition(int id, Vec3 target, float step)

Moves the entity toward a target position by up to step units. Snaps exactly onto target if already close enough.

void entityMoveTowardsEntity(int id, int targetId, float step)

Same idea as above, but targets another entity’s position.

float entityDistanceToPosition(int id, Vec3 target)
float entityDistanceToEntity(int aId, int bId)

Simple distance calculators for gameplay logic.

6. Line of Sight

uint8_t entityHasLineOfSightToEntity(int fromId, int toId)

Checks whether anything marked for hit testing blocks a direct ray between two entities.

uint8_t entityHasLineOfSightToPosition(int fromId, Vec3 pos)

Checks whether anything marked for hit testing blocks a direct ray from an entity to an arbitrary point in world space.

These are very useful for AI, triggers, turrets, interactables, and cheap indoor chunk visibility logic.
The current logic uses ENTITY_HITTEST style blockers. If you want line-of-sight to use colliders instead, the implementation can be changed to test ENTITY_COLLIDABLE instead.

7. Mesh Helpers

void meshSetVertex(Mesh *mesh, int index, Vec3 v)
void meshOffsetVertex(Mesh *mesh, int index, Vec3 delta)
void meshSetVertexRecalc(Mesh *mesh, int index, Vec3 v)
void meshOffsetVertexRecalc(Mesh *mesh, int index, Vec3 delta)

Vertex editing helpers. The Recalc versions update bounds radius afterward.

Vec3 meshGetVertex(const Mesh *mesh, int index)

Returns a mesh vertex or {0,0,0} on invalid access.

void meshTranslate(Mesh *mesh, Vec3 delta)

Moves the raw mesh vertices directly by a delta. This does not move an entity in world space. It changes the mesh itself.

void meshScale(Mesh *mesh, Vec3 scale)

Scales all mesh vertices by X/Y/Z scale values. Recalculates bounds radius afterward.

void meshRecalcBounds(Mesh *mesh)

Recomputes boundsRadius from the current vertex positions.

void meshResetFromSource(Mesh *dst, const Mesh *src)

Copies vertex positions back from a source mesh into a destination mesh with matching vertex count.

8. Bounds Anchoring

void meshAnchorToBounds(Mesh *mesh, Vec3 anchor)

Moves the mesh so a chosen point within its own min/max bounds becomes the origin. This works like a practical pivot-from-bounds helper.

  • x = -1 left, 0 center, 1 right
  • y = -1 bottom, 0 center, 1 top
  • z = -1 back, 0 center, 1 front
meshAnchorToBounds(&human, (Vec3){ 0.0f, -1.0f, 0.0f }); // bottom-center / feet
meshAnchorToBounds(&human, (Vec3){ 0.0f,  0.0f, 0.0f }); // center
meshAnchorToBounds(&human, (Vec3){ 0.0f,  1.0f, 0.0f }); // top-center / head

9. Deform / Shatter Tools

Mesh meshSeparateTriangles(const Mesh *src)

Creates a new mesh where every triangle gets its own private 3 vertices. This is perfect for effects like shattering, exploding faces outward, or per-face animation.

Warning: this is RAM goblin mode. Triangle count stays the same, but vertex count becomes triCount * 3.
void refaceMesh(const Mesh *src, Mesh *target)

Restores a separated/exploded target mesh back to the original face positions from a source mesh, but does not weld shared vertices back together.

Also restores per-face values like color, emission, transparency, roughness, and mesh material.

void meshDeformWaveY(Mesh *mesh, float time, float amount, float freq)
void meshDeformWavePlaneY(Mesh *mesh, float time, float amp, float freqX, float freqZ, float speed)

Simple built-in deformation helpers for wavy effects.

10. Collision / Ray Notes

int entityCollisionTest(...)
int entityCollision(...)
int entityMoveWithCollision(...)

Main collision helpers for gameplay movement and collision testing.

uint8_t entitySweepRaycastTest(int movingId, int targetId, Vec3 *hitPos, Tri *triHit)

Accelerated sweep raycast helper. In the current setup this routes through the SIDBOX API/hardware side.

uint8_t entityIntersectTest(int a, int b)

Mesh-vs-mesh style triangle intersection test with broad-phase checks and candidate filtering.

11. Gotchas

entityTranslate() vs meshTranslate()
entityTranslate() moves the object instance in the world.
meshTranslate() edits the actual mesh vertices.
Bounds anchoring is not “real pivot storage”
meshAnchorToBounds() is a practical pivot-style helper that repositions the mesh based on its own min/max bounds.
Separated triangle meshes use much more RAM
Use meshSeparateTriangles() for effects, not for every mesh all the time.
Good effect workflow
1. Start with source mesh
2. Make a separated copy with meshSeparateTriangles()
3. Apply per-face effects
4. Restore with refaceMesh() when needed
Indoor / chunk logic
The engine already does frustum work, but game code can still cheaply hide or show chunked sections of the world using line-of-sight checks, chunk flags, or scripted room logic.
